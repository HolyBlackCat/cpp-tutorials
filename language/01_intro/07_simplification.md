# Simplifying things

And lastly, before we begin...

The difficult part about teaching C++ is giving explanations that are *both* simple and correct, because some parts of C++ are quite complex.

You either go for simplicity and teach things "wrong", or go for correctness and create an unreadable mess.

So in this tutorial I give simplified explanations first, but clearly label them as simplified. And then revisit those explanations in later chapters.

Advanced readers can consult the list of intentional simplifications [here](../90_addendum/01_intentional_simplifications.md).
